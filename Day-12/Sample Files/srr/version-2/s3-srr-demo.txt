## AWS learning journey — Day 12

### Demo: Amazon S3 Same-Region Replication

**Version:** 2

**Source Region:** US East (Ohio) — `us-east-2`
**Destination Region:** US East (Ohio) — `us-east-2`

**Required Source Key:** `srr/s3-srr-demo.txt`

This file intentionally uses the **same filename and S3 key as Version 1**.

Upload it **after Version 1** to demonstrate S3 Versioning and the replication of subsequent object versions.

### Expected Result

* A new **Version ID** is created in the source bucket.
* The new version is replicated to the **Ohio SRR destination bucket**.
* **Show versions** displays both Version 1 and Version 2.
* Both versions remain associated with the same S3 object key.

### Data Classification

Synthetic training data only. No customer, learner, personal, confidential, or production data is stored in this object.
